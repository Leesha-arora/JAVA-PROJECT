# Voting Management System

A sophisticated Java application designed to facilitate the management of voting 
processes in elections or organizational decision-making.

## Technologies Used
- Java (Core Logic)
- HTML (Frontend UI)
- CSS (Design)
- JavaScript (Interactivity)

## Features
- Add & view candidates
- Cast a vote
- Show live results
- Backend logic in Java
- Simple web-based UI

## How to Run

### Backend (Java)
1. Open terminal
2. Navigate to backend/src
3. Run:
   javac VotingSystem.java
   java VotingSystem

### Frontend
1. Open `index.html` in any browser.

## GitHub Instructions
1. Create a new repository
